WEEK 03 · TASK 4

任務四｜在同一 repo 中加入版本三：ASDF

目標：版本三成為簡單的左手 ASDF 遊戲；放在入口網站的 v3 資料夾。

驗收：首頁能開三個版本，版本三能提示字母、亮起對應按鍵、按對得分，並且確實是同一 repo。

技能：描述互動、指定目錄、要求保留舊版本、測試並更新網站。不考 JavaScript 語法與演算法。

玩版本三 ASDF階段範例：任務四入口＋v3

本站把五個任務合併在同一個網站（repo：typing-history）。講義原本版本一、二各是獨立 repo，這裡放在 v1/、v2/ 子資料夾。

小任務 4A：先說清楚檔案放在哪裡

typing-history/
├─ index.html          ← 入口首頁，仍然要保留
├─ coming-soon.html    ← 舊預告頁可先保留
└─ v3/
   └─ index.html       ← 遊戲，不是拿來覆蓋首頁的檔案

兩個檔案都叫 index.html，位置不同，用途就不同。

小任務 4B：讓 Agent 修改

請在我目前的開發歷程網站加入版本三，建立 v3/index.html。保留根目錄 index.html 的三張卡片和版本一、二的真實網址。只把版本三卡片改連 v3/index.html，不要新建 repo，也不要連到外部網站。 遊戲畫面有英文鍵盤、目前要按的字母和分數。按開始後，在 A、S、D、F 中隨機提示一個字母，鍵盤對應按鍵亮起。使用者按對實體鍵盤按鍵加一分，接著換題；按錯不加分並保留原題。長按不連續計分。請提供開始／重新開始及停止練習，並加入回到 ../index.html 的連結。 鍵盤可用 CSS 製作，不需要另外載入鍵盤圖片或紅點 PNG。請直接完成檔案並列出我要測試的步驟，不用教我 JavaScript 語法。

小任務 4C：用行為測試

  1. 從入口首頁點版本三，確認不是還停在 Coming Soon。
  2. 按開始，畫面顯示 A、S、D、F 之一，對應鍵亮起。
  3. 故意按錯一次：不加分，原題保留。
  4. 按對一次：加一分，出下一題。
  5. 長按一個鍵：不能靠長按一直加分。
  6. 回到首頁，確認版本一、二仍正常。

回報問題範例：「我從首頁開啟 v3/index.html，按開始後畫面顯示 S，但亮起的是 D。預期字母和亮鍵一致。請只修正這個對應問題，保留得分與首頁連結。」

小任務 4D：更新原網站

  • 不建立新 repo；回到原本 typing-history。
  • 在根目錄上傳入口 index.html，並上傳整個 v3 資料夾。
  • 不要進入 repo 裡的 v3 再拖一次，否則會變成 v3/v3/index.html。
  • 從原入口網址點版本三，網址應維持同一網站，只在後面出現 /v3/。
