WEEK 03 · TASK 2

任務二｜英打遊戲版本二：外部圖片與聲音

目標：出現英文鍵盤圖片與開始按鈕；點擊開始後播放兩聲嗶聲，仍不能實際玩遊戲。

驗收：繳交版本二的獨立網站網址，圖片能顯示，按鈕能播放聲音。

技能：把外部素材交給 Agent、辨認路徑、搬動檔案後請 Agent 更新引用、保留結構上傳。

開啟版本二成果範例 A 素材放根目錄範例 B 圖片、聲音分開範例 C 共用 assets

本站把五個任務合併在同一個網站（repo：typing-history）。講義原本版本一、二各是獨立 repo，這裡放在 v1/、v2/ 子資料夾。

素材：keyboard.png（原創鍵盤示意圖）與 beep.wav（合成雙嗶聲），不用上網找。三種配置功能完全相同，只有位置不同。

三種放置方式（先會對位置，不用背程式）

放置方式圖片聲音
2A 同一層keyboard.pngbeep.wav
2B 分開放images/keyboard.pngaudio/beep.wav
2C 一起放（最後上傳這種）assets/keyboard.pngassets/beep.wav

小任務 2A：先全部放同一層

請製作英打遊戲版本 2 的預告頁。使用我提供的 keyboard.png 與 beep.wav，兩個檔案都與 index.html 放在同一層。顯示鍵盤圖片和開始按鈕，按下開始播放 beep.wav，其他地方不需要遊戲互動。請引用外部檔案，不要改為內嵌圖片或即時合成聲音。若素材找不到，顯示容易理解的訊息。請保留這些檔案名稱。

聽不到聲音時，先檢查電腦音量、瀏覽器是否靜音，再檢查檔案。

小任務 2B：圖片、聲音各有資料夾

我已把 keyboard.png 移到 images 資料夾，beep.wav 移到 audio 資料夾。index.html 留在原位。請只修正外部素材路徑，保持圖片與音效功能，不要搬回原位置，也不要改成 Base64。請列出修改後的兩個路徑供我核對。

小任務 2C：改成共用 assets

現在圖片和聲音都放在 assets 資料夾，index.html 在它外面。請更新兩個相對路徑，不改變畫面與互動。完成後告訴我哪些檔案和資料夾要一起上傳。

小任務 2D：上傳完成版並驗收

  1. 一起選取 index.html 和整個 assets 資料夾上傳。
  2. 在 GitHub 檔案列表確認圖片與聲音都在 assets 內。
  3. 啟用 Pages，用網站網址開啟，請同學確認圖片與聲音，不只檢查標題。

路徑規則

  • / 表示往下一層；網頁路徑用 /，不用 Windows 的反斜線。
  • 路徑從使用資源的 HTML 所在資料夾出發。
  • C:/Users/... 是你的電腦位置，其他人不能用。
  • 不要在最前面加 /，否則線上會跳過專案資料夾。
  • Keyboard.png 與 keyboard.png 在線上可能是不同檔名。

停下來檢查：本機正常、線上失敗時，先比對檔案是否齊全、位置是否一樣，再請 Agent 修正，不要一口氣換整個遊戲程式。
