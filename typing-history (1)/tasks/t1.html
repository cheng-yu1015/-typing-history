WEEK 03 · TASK 1

任務一｜英打遊戲版本一

目標：畫面只有「英打遊戲版本一」字樣與開始按鈕；完全沒有互動與遊戲內容。

驗收：繳交自己獨立的 GitHub Pages 網址，別人可以正常開啟。

技能：指揮 Agent 產生頁面、找到 index.html、上傳部署、分辨網站與 repo 網址。不是手寫 HTML 考試。

開啟版本一成果

本站把五個任務合併在同一個網站（repo：typing-history）。講義原本版本一、二各是獨立 repo，這裡放在 v1/、v2/ 子資料夾。

小任務 1A：請 Agent 做出畫面

請在我的 typing-v1 資料夾建立 index.html。畫面是白色空白頁，只放「英打遊戲版本一」標題與一個寫「開始」的按鈕。不加說明文字、圖片、動畫或遊戲互動，按鈕不需要有任何作用。所有必要的樣式放在同一個 HTML 裡。完成後告訴我檔案位置。

完成檢查：本機用瀏覽器開啟，只有指定字樣與按鈕。按按鈕沒有反應是正確的，不需要修理。

小任務 1B：第一次上線

  • 建立 repo，只上傳資料夾內的 index.html（最外層，不要多包一層）。
  • Settings → Pages → Deploy from a branch → main / (root)。
  • 用 GitHub Pages 網址開啟，不是只能從電腦的檔案位置看到。

小任務 1C：讓同學打開

複製網站網址給同學，請同學確認「標題正確、按鈕出現」，把網址記入《繳交與驗收紀錄》。

種類格式示意繳交？
repo 檔案頁https://github.com/你的帳號/typing-v1不是主要驗收網址
網站https://你的帳號.github.io/typing-v1/繳交這個
本機檔案file:///C:/.../index.html其他電腦不能用

停下來檢查：如果這一關無法部署，先找老師或同學確認 repo、index.html 位置與 Pages 設定，不急著做後面遊戲。
